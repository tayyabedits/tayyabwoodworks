Tayyab Woodworks website

index.html  = aap ki website (hosting par upload karein)
admin.html  = product add/badalne ka page

Badlav ka tareeqa:
1. admin.html browser mein kholein.
2. "Step 1" mein apni index.html chunein.
3. "+ Naya product add karein" dabayein: 1) Photo, 2) Naam aur Qeemat, 3) Details.
4. "Nayi index.html download karein" dabayein.
5. Nayi index.html hosting par purani ki jagah upload karein.

CSV / TXT se products import:
- admin.html > Products > "File se products import karein"
- Har line ek product: name, category, price_pkr, description, image
- Image wale column mein photo ka naam (door1.jpg) ya image ka link likhein.
- Photo ke naam likhe hon to pehle "Photos chunein" se wo photos chunein, phir CSV/TXT file chunein.
